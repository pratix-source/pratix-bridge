Pratix Bridge local preview

Do not open client/index.html directly.

Pratix Bridge is a Vite browser app. A browser cannot resolve its source modules from file://, so the transfer interface must be opened through a local preview server or its published Vercel URL.

  1. Install Node.js 22+ and pnpm.
  2. Double-click START-PRATIX-BRIDGE.bat on Windows, or run chmod +x START-PRATIX-BRIDGE.command && ./START-PRATIX-BRIDGE.command on macOS/Linux.
  3. Open http://localhost:3000 when the terminal reports that the server is running.

For the requested public setup, upload the project to GitHub, import it in Vercel, and select Deploy. The included configuration requires no environment variables, database, or server setup.
